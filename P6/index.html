Introduction

HTML (HyperText Markup Language) is the standard language for creating and structuring web pages using tags and elements. It defines how content like text, images, and links appear in a browser.
  • It is a markup language, not a programming language .
  • This means it annotates text to define how it is structured and displayed by web browsers.
  • It is a static language, meaning it does not inherently provide interactive features but can be combined with CSS for styling and JavaScript for interactivity.

What is HTML ?

HTML (HyperText Markup Language) is the standard markup language used to create and structure content on the World Wide Web. It acts as the "skeleton" of a webpage, defining elements like headings, paragraphs, images, and links, which web browsers then interpret and display as a visible page.
    Key Concepts
  • Markup Language, Not a Programming Language: HTML uses a system of tags to annotate text and data, telling the browser how to display content. It does not perform dynamic functions or logic like a programming language such as JavaScript.
  • Elements and Tags: An HTML document is built from elements, which are represented by tags.
  • Opening Tag: Marks the beginning of an element.
  • Some elements are "empty" and do not require a closing tag, such as the <img> tag for images or the <br> tag for a line break.
  • Attributes: These are used within the opening tag to provide additional information about an element, such as the source file for an image (src) or the destination URL for a link (href).
  • Content: The information displayed to the user (e.g., This is a Heading).
  • Closing Tag: Marks the end of an element (e.g., </h1>).

What is JavaScript ?

JavaScript is a versatile, high-level programming language that enables interactive content and dynamic features on websites. It is one of the three core technologies of the World Wide Web, working alongside HTML (structure) and CSS (styling) to create modern web experiences. Key Features
  • Client-Side Execution: JavaScript code primarily runs directly in the user's web browser, which allows for faster response times and reduces server load. All major browsers have a built-in JavaScript engine to execute this code.
  • Dynamic Typing: Variables in JavaScript are dynamically typed, meaning a single variable can hold different data types (like a number or a string of text) at different times.
  • Object-Oriented & Functional: It supports multiple programming paradigms, including object-oriented, functional, and event-driven styles, providing flexibility for developers.
  • DOM Manipulation: JavaScript can dynamically modify the content, structure, and styles of a web page in real-time through the Document Object Model (DOM).
  • Asynchronous: It handles tasks like fetching data from a server in the background without freezing the user interface, a crucial feature for modern, responsive applications.
